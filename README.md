# Kode-Lord_MW

Repo latihan. Proyek-proyek yang sudah jadi situs sendiri dipindahkan ke repo
masing-masing agar tiap proyek punya GitHub Pages sendiri di root dan
pengaturannya tidak saling menimpa.

## Proyek yang sudah pindah

| Proyek | Repo | Situs |
|---|---|---|
| Quiz sertifikasi RTA & CTA | [teknikaldrill](https://github.com/BeixuanTianjun/teknikaldrill) | https://beixuantianjun.github.io/teknikaldrill/ |
| Portofolio | [portfolio](https://github.com/BeixuanTianjun/portfolio) | https://beixuantianjun.github.io/portfolio/ |
| Spill de Tea | [spill-de-tea](https://github.com/BeixuanTianjun/spill-de-tea) | https://beixuantianjun.github.io/spill-de-tea/ |

Riwayat commit tiap proyek ikut dipindahkan dengan `git subtree split`, jadi
riwayat lengkapnya ada di repo tujuan, bukan di sini.

## Yang tersisa di repo ini

- `Simple_Calculator/Tombol_lampu.html` — latihan tombol lampu nyala/mati
- `Volume_Bola.html` — latihan hitung volume bola
- `brand/` — banner LinkedIn beserta berkas sumbernya

Ketiganya bukan situs yang diterbitkan, jadi GitHub Pages untuk repo ini sudah
tidak diperlukan dan bisa dimatikan lewat **Settings → Pages → Source: None**.
